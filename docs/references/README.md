# Références visuelles — Power & Skill Bible v0.4

Planches de référence validées par Milan pour les 15 compétences de la
`RANK_ZERO_POWER_SKILL_BIBLE v0.4`, archivées ici pour devenir la référence
permanente, consultable par n'importe quelle session future (avant cet
archivage, elles n'existaient que dans l'historique de discussion).

Chaque image est un recadrage (crop) d'une planche source multi-compétences
fournie par Milan (4 images, une par upload), une planche par compétence,
recadrée à ses propres limites verticales (en-tête + 4 panneaux narratifs +
colonne "Assets Détachés"/"Assets - Effets"). Recadrage effectué par script
Python/Pillow (crop vertical sur bornes de lignes détectées), sans aucune
retouche de contenu.

## Assets partagés (`shared/`)

Deux planches source (upload 3 et upload 4) portent chacune, en pied de
page, un même bloc de référence transverse — non spécifique à une
compétence : sprites de base du personnage (8 états), icônes des 3 classes
de pouvoir, et 5 icônes d'effets communs (Impact, Poussière, Fissure,
Débris, Onde de choc). Les deux occurrences sont archivées séparément
(contenu visuellement quasi identique dans les deux, mais provenance
distincte conservée par prudence plutôt que de n'en garder qu'une) :

## Portée de cet archivage

Cet archivage couvre les 15 compétences pour lesquelles Milan a fourni une
planche de référence. Les autres compétences de la bible ("11 compétences
restantes") n'ont ni planche ni implémentation à ce stade — leur
priorisation viendra dans un mandat ultérieur, non entamé ici.
